## Problem Statement

Electrooculography (EOG) signals generated by eye movements can be used as an alternative human–machine interaction method for individuals who have limited hand movement or require hands-free control. Existing eye-tracking systems are often expensive, camera-dependent, computationally intensive, or unsuitable for real-time embedded applications.

The aim of this project is to design and develop a **low-cost EOG-based 3D target selection and robotic manipulator control system** that uses horizontal and vertical eye movements along with blink detection to perform real-time cursor positioning, target locking, and command execution through signal processing and embedded control techniques.

---

## Abstract

Human–machine interaction systems based on biological signals are becoming increasingly important in assistive technology, robotics, and hands-free control applications. This project proposes an **EOG-based 3D Target Selection and Robotic Manipulator Control System** that enables a user to control a virtual 3D workspace and issue commands using eye movements and blink patterns.

EOG signals are acquired using a BioAmp sensor and digitized through an ADS1115 analog-to-digital converter interfaced with an Arduino Uno. The data is transmitted to a Python-based application where notch filtering, bandpass filtering, drift removal, and Kalman smoothing are applied for reliable signal extraction.

Horizontal and vertical eye movements are mapped to top-view and side-view target positioning, while blink detection is used for mode switching and final target confirmation. The system includes a PyQt6 graphical user interface displaying live signal graphs, target position, and selection status.

The proposed solution aims to provide a low-cost, portable, and real-time alternative to camera-based eye-tracking systems. Expected applications include assistive robotic control, rehabilitation systems, smart interfaces, and accessible human–computer interaction for users with motor impairments.

## Proposed System

The proposed system uses **EOG signals generated by eye movements** to control a virtual 3D target selection environment and issue control commands.

### Working Principle

1. EOG electrodes capture horizontal and vertical eye movement signals.
2. BioAmp amplifies the signals.
3. ADS1115 converts the analog signals to digital data.
4. Arduino transmits the data to a computer through serial communication.
5. Python processes the signals using filtering and smoothing algorithms.
6. Detected eye movements control target movement in top and side views.
7. Blink patterns are used for mode switching and final target confirmation.

### Major Components

- EOG electrodes
- BioAmp EXG Pill
- ADS1115 ADC
- Arduino Uno
- Python application
- PyQt6 GUI

## Methodology

### 1. Signal Acquisition
- Capture horizontal and vertical EOG signals using electrodes.
- Amplify using BioAmp.
- Convert to digital form using ADS1115.
- Transmit data through Arduino.

### 2. Preprocessing
- Apply 50 Hz notch filter.
- Apply 0.1–10 Hz bandpass filter.
- Remove baseline drift.
- Apply Kalman smoothing.

### 3. Feature Extraction
- Detect horizontal glances.
- Detect vertical glances.
- Detect blink events.

### 4. Target Selection
- Control top-view target position.
- Control side-view target position.
- Perform target lock and confirmation.

### 5. Visualization and Control
- Display live EOG graphs.
- Show target position and selection status.
- Generate robotic manipulator commands.
